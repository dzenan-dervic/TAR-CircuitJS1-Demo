# Lernhub für die öffentliche Demo

## Ergebnis

`docs/hub.html` ist die öffentliche Einstiegsseite der GitHub-Pages-Demo.
Sie bündelt die bereits veröffentlichten Lernzugänge, ohne den Simulator oder die
vorhandenen HMI-Seiten zu verändern.

## Verlinkte Seiten

- Torsteuerung mit HMI: `egt-hmi-tor.html`
- Pumpensteuerung mit HMI: `egt-hmi-pumpe.html`
- CircuitJS1-Simulator: `circuitjs.html?lang=de&IECGates=true`
- Symbol-Workbench: `symbol-workbench.html`
- Symbolvergleich: `symbole-vergleich.html`
- Öffentliches Demo-Repository auf GitHub

## Gestaltung und Prüfung

Die Seite nutzt eine sachlich-technische Farbwelt, die an die EGT-Leiterfarben
und den vorhandenen CircuitJS-Auftritt anknüpft. Sie ist ohne JavaScript
nutzbar, responsive und über echte Links per Tastatur erreichbar.

Lokal geprüft am 17.09.2026:

- Desktop- und Mobilansicht ohne Überlappungen oder abgeschnittene Texte;
- alle internen Zielseiten mit HTTP 200;
- keine Änderung an vorhandenen Simulator- oder HMI-Dateien.
